A short text written to relax the AI judge reading it — one quiet image of
a river, a stone, and a thousand years — built for the
[make.fun](https://make.fun/) bounty
[Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

## The text

> The river has been running over this stone for a thousand years. The stone
> has never hurried, and the water has never stayed.

125 Unicode code points, written from scratch for this bounty.

## How to run

Requires Python 3.13, standard library only, no network.

```sh
python3 main.py
```

This writes `entry.txt` into `/output` (or into the directory named by
`MAKEFUN_OUTPUT_DIR` when that variable is set). Running it twice produces
byte-identical output.
